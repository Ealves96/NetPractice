## 📝 Description
NetPractice est un projet pratique qui m'a permis de plonger dans le monde fascinant de la réseautique. À travers 10 niveaux progressifs, j'ai pu mettre en pratique mes connaissances théoriques sur les réseaux TCP/IP et développer une compréhension approfondie de la configuration réseau.

## 🎯 Objectifs du Projet
- Comprendre et maîtriser l'adressage IP
- Configurer des réseaux de petite taille
- Résoudre des problèmes de connectivité réseau
- Apprendre à utiliser des routeurs et autres périphériques réseau
- Développer une approche méthodique pour la résolution de problèmes réseau

## 🚀 Fonctionnalités
- Interface web interactive pour l'apprentissage
- 10 niveaux progressifs de difficulté
- Système de validation en temps réel
- Exportation des configurations pour suivi
- Environnement d'entraînement sécurisé

## 💡 Ce que j'ai appris
- Configuration d'adresses IP et sous-réseaux
- Gestion des masques de sous-réseau
- Configuration de routeurs
- Résolution de problèmes de connectivité
- Compréhension approfondie du protocole TCP/IP
- Méthodologie de diagnostic réseau
- Gestion des passerelles par défaut
- Configuration des interfaces réseau

## 📋 Comment utiliser
1. Clonez ce dépôt
2. Ouvrez le fichier `index.html` dans votre navigateur
3. Entrez votre login pour commencer l'entraînement
4. Suivez les instructions pour chaque niveau
5. Exportez vos configurations avec le bouton "Get my config"
